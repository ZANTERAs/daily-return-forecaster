# Daily-Bar 20-Day Return Forecaster

A bidirectional LSTM with soft attention that predicts a stock's **20-day
forward return** (~1 trading month) on **daily bars**, expressing its
uncertainty as a calibrated **P10 / P50 / P90 band** rather than a single
number.

The model is **ticker-agnostic**: change one line (`TICKER`) and everything
else — sector ETF, quantile width, earnings calendar — auto-configures from the
data.

> ⚠️ **Disclaimer**: This is a research and educational project, not financial
> advice. Forecasts are probabilistic and frequently wrong. Do not trade real
> money based on its output.

---

## Highlights

- **Return target, not price** — predicts `100 × (close[t+20] − close[t]) / close[t]`,
  removing the price-persistence shortcut that lets naive models look accurate
  while learning nothing.
- **Quantile regression** — P10/P50/P90 via pinball loss gives an ~80%
  confidence interval instead of a fragile point estimate.
- **Rank-correlation loss** — a differentiable soft-Spearman term pushes the
  model to *rank* returns correctly, directly improving Information Coefficient.
- **Walk-forward validation** — 5 expanding folds with a rolling 1-year
  validation window, so metrics reflect out-of-sample performance across regimes.
- **5-model ensemble** — final forecast averages 5 independently seeded models.
- **Auto-configuration per ticker:**
  - Sector ETF detected from the stock's GICS sector via `yfinance` (e.g. MSFT → XLK).
  - Quantile bands auto-widen to P05/P95 for high-volatility names.
- **Sharpe backtest** — a long/short backtest on the P50 signal reports whether
  the signal would actually have been tradeable.
- **Run metadata** — every run writes `<TICKER>_model_metadata.json` with the
  full config, test metrics, backtest stats, and the latest forecast.

## How it works

| Stage | Detail |
|-------|--------|
| **Bars** | Daily (`auto_adjust=True`), 15 years of history |
| **Input window** | 60 trading days |
| **Target** | 20-day forward percentage return |
| **Backbone** | 2-layer bidirectional LSTM (hidden=64) + soft attention |
| **Head** | Linear → 3 quantiles (P10/P50/P90, or P05/P50/P95 if volatile) |
| **Loss** | 70% pinball (quantile) + 30% soft-Spearman on P50 |
| **Optimizer** | Adam (lr=3e-4) + ReduceLROnPlateau + early stopping |
| **Validation** | 5-fold walk-forward, rolling 252-day val window |
| **Final model** | Ensemble of 5 seeds, averaged quantile predictions |

### Feature set (17)

| Group | Features |
|-------|----------|
| Technicals (10) | Close, Volume, EMA_20, RSI_14, MACD, OBV, GC_spread, BB_width, ATR_14, STOCH_K |
| Market context (3) | SPY 20-day return, sector-ETF 20-day return, 10-yr Treasury yield change |
| Realized volatility (3) | rolling daily-return std over 5 / 20 / 60 days |
| Earnings (1) | flag for the 7 calendar days before each earnings date |

## Installation

Requires Python 3.10+.

```bash
pip install -r requirements.txt
```

---

## Usage

Open `main.py`, set the ticker near the top, and run:

```python
TICKER = "MSFT"   # the only line you need to change
```

```bash
python main.py
```

This runs walk-forward validation, trains the 5-model ensemble, prints a
test-set evaluation + backtest, and opens an interactive Plotly chart with the
prediction band and the 20-day forecast.

---

## Outputs

Per ticker, running `main.py` produces:

- `<TICKER>_lstm_e0.pt … e4.pt` — the 5 trained ensemble weights *(git-ignored)*
- `<TICKER>_model_metadata.json` — full run snapshot (config, metrics, backtest, forecast)
- an interactive Plotly chart (test-set band + forward forecast)

## Metrics glossary

| Metric | Meaning | Baseline / target |
|--------|---------|-------------------|
| **DirAcc** | % of times `sign(P50) == sign(actual)` | 50% = random; high in trending markets even without skill |
| **IC** | Information Coefficient — Pearson `corr(P50, actual)` | 0.00 = random; >0.10 useful; >0.30 strong |
| **Coverage** | % of actual returns inside the P10–P90 (or P05–P95) band | ideal ≈ 80% / 90% to match the band |
| **RMSE / MAE** | Error of P50 in percentage points | lower is better |
| **Sharpe** | Annualized risk-adjusted return of the P50 long/short signal | >0.5 = decent |
| **Max DD** | Largest peak-to-trough drawdown of the backtest equity curve | lower is better |

## Notes

- Model weights (`*.pt`) are intentionally **not** committed — they are
  regenerated by running `main.py`. Everything needed to reproduce them is in the code.
- CPU-only is fully supported; CUDA is used automatically if available.
- Data is pulled live from Yahoo Finance via `yfinance`, so an internet
  connection is required and exact numbers drift as new market data arrives.
